Chip Slicer Hierarchy is a slicer made of buttons — chips — that drills down through up to three levels, such as Category → Subcategory → Product or Country → Region → City. You put the fields in one well, in order, and the order is the hierarchy. Click a chip to filter the page; open it to see its children. The selection is a standard Power BI filter, so it works with sync slicers, bookmarks and edit interactions.

The slicer is complete without a licence. A Pro plan adds three things: a search box, colour by value and drop-down mode. See Free and Pro.

Quick start

  1. Add Chip Slicer Hierarchy from AppSource (Visualizations pane → Get more visuals).
  2. Drag up to three columns into Categories, in order: the first field is level 1, the second sits under it, the third under that.
  3. Click a chip to filter the page. Click the arrow on a chip (▼) to open its children without filtering.
  4. Optional: drag a measure into Values and turn on Format → Value Badge → Show value badge.
  5. In the Format pane, Style template changes the look of all three levels in one click.

While you edit, a tips bar at the bottom of the visual offers the templates and “Try Pro” buttons; hide it with ✕ (it comes back from Format → Style template → Show setup tips). It never shows in reading view.

Selecting, opening and clearing

  • Select: click a chip. Selecting a chip with children also opens it, so you see the next level.
  • Open without filtering: click the arrow on the chip (▼ / ▲). Turn the arrow off with Hierarchy → Show expand icon.
  • Multi-select (on by default): every click adds or removes a chip. With it off, a click replaces the selection; Ctrl+click still adds.
  • Leaf-only selection: only the chips of the last level can be selected; upper levels are for navigating only.
  • Auto-collapse siblings: opening a chip closes the others at the same level.
  • All chip: clears the selection. Its text can be changed.
  • Clear button ✕: next to the search box or the drop-down bar, otherwise in the top-right corner. It only shows when something is selected. On by default (Hierarchy → Show reset button).
  • Default selection: None, First value (the first level-1 chip) or These values, with a list separated by commas, e.g. Spain, France. Values are matched at any level, without case or accents. It applies when the slicer opens with nothing selected; if the user clears it, the slicer stays clear until the page is opened again. With multi-select off, only the first match is used.

Which level filters? The filter applies to the deepest level that has a selection. If you select Europe (level 1) and then Spain (level 2), the page is filtered by Spain. To filter by several countries, select several countries.

The selection is a standard Power BI filter: it follows sync slicers, is saved in bookmarks, respects edit interactions and appears in the filter pane. When another visual highlights data and there is a measure in Values, the chips outside the highlight are dimmed.

On-object formatting

With Format on, click a chip, a value badge, the clear button, the search box or the drop-down bar to see its options next to it, with quick toggles (multi-select, leaf-only, drop-down mode…) and a link to its card in the Format pane. In format mode a click chooses what to format and does not filter. As with native visuals, the first click selects the visual and the second the part.

Languages, number formats and accessibility

  • Format pane and texts in English, Spanish, Portuguese (Brazil and Portugal), French, German, Italian, Dutch, Polish, Japanese, Chinese (Simplified) and Korean, following the language of Power BI — including the licence notice and the watermark.
  • Dates and numbers on the chips use the column's format in the model. The value badge with Model format uses the measure's format string, dynamic format strings included, in the report's language.
  • Keyboard: one Tab stop for the whole slicer; arrow keys, Home and End move between chips; Right opens a chip with children and Left closes it; Enter or Space selects (Ctrl adds); Escape clears the selection or closes the drop-down; Shift+F10 opens the context menu.
  • Screen readers: each chip is a button with its state (selected, open or closed) and its value.
  • High contrast: the chips take the colours of the Windows high-contrast theme; colour by value is not applied there, so meaning never depends on the fill alone.

Troubleshooting

Clicking a chip does not filter the other visuals

Check Format → Edit interactions: the other visuals must be set to filter from this slicer. Check also that the fields in Categories are related to the tables of the other visuals in the model.

I selected a parent and its child, and the page only shows the child

That is by design: the filter applies to the deepest level with a selection. Select only parents to filter by parents, or select all the children you need.

A level does not appear
  • Check the order and number of fields in Categories: at most three, and the order is the hierarchy.
  • Click the arrow on the parent chip, or select it: children appear when the parent is open.
  • With Hide blank values on, a path stops at the first blank value, so blank children are not shown.
Images do not show

The Images column must contain a Base64 data URI that starts with data:image/. Web addresses (https://…) are not loaded, by design. Each image column matches a level by position: the first image column goes with the first category field.

Some values are missing
  • Other filters on the page or report reduce the values, as with any slicer.
  • Beyond 2,000 rows the rest are not loaded. Split the hierarchy with another slicer or a page filter.
  • With Hide blank values on, blanks are left out.
The default selection does not apply
  • It only applies when the slicer opens with nothing selected. A bookmark or a saved selection wins.
  • The text must match the chip text. Separate values with commas.
  • With Leaf-only selection on, only values of the last level can match.
  • If the value is filtered out by another filter, there is nothing to select.
The drop-down list is cut off

A custom visual can only draw inside its own area, so the open list appears inside the visual, not over the page. Make the visual as tall as the open list should be; when closed, only the bar is drawn at the top.

I see “Pro preview” on the slicer

You turned on a Pro feature without a licence. It is shown only to you while editing; readers see the free chips. Turn the feature off, or get the Pro plan to remove the watermark.

I chose a template and some colours did not change

A template changes only what it defines. Use Reset to default on a colour to let the template decide it.

The tips bar covers my chips

It only appears while you edit. Close it with ✕ or turn off Format → Style template → Show setup tips.

Frequently asked questions

Is it free? What does Pro add?

The slicer is complete without a licence: three levels, images, value badges, tooltips, templates, default selection, keyboard and languages. Pro adds three things: the search box, colour by value and drop-down mode. Limits (3 levels, 2,000 rows) are the same in both.

How do I buy Pro?

From the offer on Microsoft AppSource, plan chipslicer-hierarchy-pro, or from the Upgrade bar Power BI shows when you turn on a Pro feature. Prices and any trial are shown on the AppSource listing.

I bought Pro and still see the watermark

The licence is assigned in the Microsoft 365 admin center to the user who opens the report. Once assigned, close and reopen Power BI Desktop or reload the report in the service so Power BI reads the licence again. If it persists, write to support@tcviz.com.

Do readers of my report need a Pro licence?

The licence is checked for the person viewing the report. Viewers without a licence see the free chips, with no watermark and no prompt — the report still works for them, without the Pro features.

What is “Pro preview”?

Without a licence, while you edit, a Pro feature you turn on is drawn working under a watermark so you can try it on your data. In reading view, and where licences cannot be read (Publish to Web, embedding, export), the free result is drawn with no watermark. See Pro preview.

How many levels can I use?

Up to three: the Categories well takes three fields. One field gives a flat chip slicer; two or three give a hierarchy.

Can I use a date hierarchy or a model hierarchy?

Yes: drop its levels into Categories (for example Year, Quarter, Month). Each field you keep becomes one level, up to three.

Which level does the filter use when I select at several levels?

The deepest level with a selection. See Selecting, opening and clearing.

How do I open a level without filtering?

Click the arrow on the chip, or focus the chip with the keyboard and press Right. Selecting a chip also opens it.

Can only the last level be selectable?

Yes: Chip Style → Leaf-only selection. Upper chips are then for navigating only.

How do I clear the selection?

Click ✕, the All chip, or the selected chip again; with the keyboard, press Escape.

Can the report open with values already selected?

Yes: Chip Style → Default selection → These values, and type them in Default values, e.g. Spain, France. Or First value to select the first level-1 chip.

Do bookmarks and sync slicers work?

Yes. The selection is a Power BI filter: bookmarks save and restore it, and View → Sync slicers keeps it across pages.

How do I add images to the chips?

Add a column with a Base64 data URI (data:image/png;base64,…) to the Images well, one column per level in the same order as Categories. You can build it in Power Query with "data:image/png;base64," & Binary.ToText(Web.Contents("…"), BinaryEncoding.Base64) — the image is fetched once at refresh and stored in the model.

Why are image web addresses not loaded?

Because the visual makes no network calls. An address such as https://…/logo.png would be a request from your report to another server; a data URI is already inside your model.

What do the value badges show on parent chips?

The measure added up over the rows under that chip: a country shows the total of its regions. For a measure that does not add up (an average, a distinct count), a parent shows the sum of its rows, so use the badge on the last level or a measure that adds up.

Which number formats can the value badge use?

Model format (the measure's own format string, dynamic format strings included), Compact (K / M / B, the default), Number, Currency and Percentage. Value Badge → Format.

How does colour by value work? Pro

With a measure in Values, each chip is tinted between the Low and High colours by its value, scaled within its own level, so a child is compared with its siblings, not with the top of the hierarchy. The selected chip keeps its selected colour, and the text switches between dark and light to stay readable.

How does the search box work? Pro

Type and the slicer shows the chips that match at every level, with the matching text marked and the number of results. Clicking a result selects it like any chip. ✕ clears the search and the selection.

How big should the visual be in drop-down mode? Pro

The list opens inside the visual's own area — Power BI does not let a custom visual draw over the rest of the page. Size the visual for the open list (for example the height of eight to ten chips), and place it where the space below the bar is free. Closed, only the bar at the top is drawn.

How do I close the drop-down?

Click the bar again or press Escape. With multi-select off, selecting a chip of the last level closes it, like a native drop-down.

Does it work with dates, numbers, codes such as 08001 and tables with a dot in the name?

Yes, since 1.3. The filter uses the original value and type, so a text code keeps its leading zeros, and dates and numbers use the column's format on the chips.

Does it react to other visuals?

Yes. When another visual highlights data and there is a measure in Values, the chips outside the highlight are dimmed.

Does it work in the Power BI service, apps and mobile?

It works wherever custom visuals from AppSource work. Where Power BI disallows interactions (some exports and embedded views), the chips are shown but do not change the filter.

Can I use it with the keyboard?

Yes. See Languages, number formats and accessibility.

What is the difference with Chip Slicer?

Chip Slicer is our free single-level slicer, with a grid layout and sorting. Chip Slicer Hierarchy is for two or three nested levels.

Does the visual send my data anywhere?

No. It makes no network calls, has no telemetry, sets no cookies and stores nothing outside the report. The links on the start screen open only when you click them, through Power BI. See the privacy policy.
