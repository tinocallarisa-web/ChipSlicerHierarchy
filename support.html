Quick start

  1. Add the visual to your report canvas.
  2. Drag one or more fields into Categories, in the order you want them nested: the first field is the top level, the next one sits under it, and so on.
  3. Click a chip to filter the rest of the report. Click it again to clear it.
  4. Click the arrow on a parent chip to expand or collapse its children.

That is the whole setup. Everything else — images, value badges, colours, tooltips — is optional.

Field wells

WellTypeWhat it does
CategoriesGroupingThe hierarchy itself. Field order defines the nesting: field 1 is the top level, field 2 its children, and so on. One field gives you a flat chip slicer. Required.
ImagesGroupingAn image shown inside each chip. Must be a Base64 data URI (data:image/*;base64,…). External http(s):// URLs are rejected on purpose — see the FAQ. Optional.
ValuesMeasureA measure shown as a badge on each chip — a count, a total, a share. Optional.
TooltipsGrouping or measureExtra fields shown when hovering a chip. Optional.

Free vs. Pro

The slicer is complete without a licence. Pro adds two things: finding what you need in a large hierarchy, and seeing where the weight is.

FeatureFreePro
Hierarchy levelsUp to 3Up to 3
Values in the hierarchyUp to 2,000Up to 2,000
Single and multi-select, drill-down, auto-collapseYesYes
Per-level colours, images, value badges, reset buttonYesYes
Keyboard activation and high-contrast supportYesYes
Search box — filter chips across the whole hierarchy, with matches highlighted and a result count—PRO
Value heatmap — colour each chip by its measure, so the weight of the hierarchy is visible at a glance—PRO

Without a licence these are simply not applied, and Power BI shows its own notification with a link to obtain one — the setting you changed is kept and takes effect as soon as the licence is active. Licence status is resolved through the official Power BI licensing API; TCViz runs no licence server and receives no data from your report.

Each level has its own card: Inactive background / border / text, Active background / border / text, and — for levels 1 and 2 — Parent-of-selection background / border / text, which highlights the ancestors of whatever is selected.

Accessibility

  • Chips are reachable with Tab and activated with Enter or Space.
  • The right-click context menu is available on chips.
  • High-contrast themes are honoured: the visual follows the Power BI palette instead of its own colours.
  • Chips carry ARIA labels so screen readers announce the category and its state.

Arrow-key navigation between chips is not implemented yet. If that blocks you, please open an issue — it helps us prioritise.

Frequently asked questions

How do I build a hierarchy?

Put several fields in the Categories well, in order. There is no separate well per level: the order of the fields is the hierarchy. The well takes up to three fields, and the hierarchy up to 2,000 values. Both limits are the same in the Free and Pro tiers — nothing is reduced for a Free user.

My images do not show. Why?

The Images well only accepts Base64 data URIs (data:image/png;base64,…). External URLs are rejected at parse time and never requested. This is deliberate: it stops the visual from making outbound network calls, which is an AppSource security requirement. Convert your images to Base64 in Power Query or with a small script — see the Tips & Hints page of the sample report.

How do I clear all selections?

Click the ‘All’ chip, or the Reset button if you enabled it under Hierarchy. Both are available in the Free tier.

What exactly does Pro unlock?

Two things, as of 1.1.0.0: the search box, with matches highlighted and a result count; and the value heatmap, which colours each chip by its measure. Everything else — all three hierarchy levels, multi-select, per-level colours, auto-collapse, images, value badges, the reset button — works without a licence. The visual supports up to three levels and 2,000 values, and those limits are identical in both tiers: nothing is reduced for a Free user. If you read older Terms that described smaller limits in Free, those were never implemented and the text was corrected in 1.0.0.4.

Does it work in Power BI Service?

Yes. Desktop and Service are both supported, as are Power BI mobile apps.

Does the visual send my data anywhere?

No. All processing happens inside Power BI on your machine or tenant. The visual makes no network requests and stores nothing outside the report. See the Privacy Policy.
