--- LONG DESCRIPTION (main video) ---

Chip Slicer Hierarchy is a Power BI custom visual that turns filtering into a modern, chip/pill-style hierarchy slicer. Drop several fields into one well and the field order becomes the hierarchy — click a chip to drill down.

In this video you'll see how to set it up in a real report, how the hierarchy expands and filters as you click, and the difference between the Free and Pro tiers.

WHAT IT DOES
• Hierarchical chip/pill slicer with drill-down filtering, no level limit
• Click a chip to filter — child chips expand automatically
• Optional image per chip and a value badge (compact / number / currency / percent)
• Optional tooltip fields shown on hover
• Fully theme-able: colors, fonts, spacing, per-level color sets

FREE vs PRO
The slicer is complete without a licence. Pro adds one feature.

Free:
• Unlimited hierarchy levels and values per level
• Multi-select and leaf-only selection
• Custom per-level colors
• Auto-collapse siblings and configurable reset button
• Image chips, value badges and tooltips

Pro:
• Everything in Free, plus the search box — filter chips across the whole hierarchy
  as you type. That is the only licensed feature.
