--- LONG DESCRIPTION (main video) ---

Chip Slicer Hierarchy is a Power BI custom visual that turns filtering into a modern, chip/pill-style hierarchy slicer — with drill-down across up to 3 levels: Category → SubCategory → Product.

In this video you'll see how to set it up in a real report, how the hierarchy expands and filters as you click, and the difference between the Free and Pro tiers.

0:00 Wrap-up

WHAT IT DOES
• Hierarchical chip/pill slicer with drill-down filtering (up to 3 levels)
• Click a chip to filter — child chips expand automatically
• Optional image per chip and a value badge (compact / number / currency / percent)
• Optional tooltip fields shown on hover
• Fully theme-able: colors, fonts, spacing, per-level color sets

FREE vs PRO
Free:
• 2 hierarchy levels, up to 20 values per level
• Single-select only

Pro:
• 3 hierarchy levels, unlimited values per level
• Multi-select and leaf-only selection
• Search box
• Custom per-level colors
• Auto-collapse siblings
• Configurable reset button
