Chip Slicer Hierarchy 1.1.1.0. Full notes: docs/CERTIFICATION-NOTES.md in the repo below.

WHAT CHANGED IN 1.1.1.0
Licence fix only; no feature, data or UI change. 1.1.0.0 is published. Its licence check
compared spIdentifier with "chip-slicer-hierarchy-tcviz", which is not a plan of this
offer, and used strict equality, while the Licensing API returns the full Service ID
(publisher.offer.plan). Pro never unlocked for a buyer. The check now matches the real
Pro plan "chipslicer-hierarchy-pro", as the full Service ID or the Plan ID on its own.

LICENCE
Official IVisualLicenseManager only (getAvailableServicePlans). Active and Warning (grace
period) accepted. isLicenseUnsupportedEnv and isLicenseInfoAvailable honoured: no purchase
prompt where a Pro customer cannot be recognised. Nothing is notified before the licence
resolves. No licence server, no external auth, no payment in the visual. No watermark, no
artificial free limits. Purchase path: notifyFeatureBlocked and notifyLicenseRequired.

DATA
Only the categorical dataView (Categories, Images, Values, Tooltips). No fetch, no XHR, no
local file access. The Images role accepts only data:image/*;base64 URIs; every other
scheme is rejected before img.src, so the visual makes no outbound request.

TIERS
Free: the whole slicer - all 3 levels, single/multi/leaf selection, drill-down,
auto-collapse, per-level colours, image chips, value badges, reset and All chips,
cross-filtering, highlighting, bookmarks, keyboard, high contrast.
Pro: Search (Pro) and Value Heatmap (Pro).

TEST
Add fields to "Categories" - the field order is the hierarchy. Without a licence turn on
Search (Pro) > Show search box: no box appears and Power BI raises its notification. Bind
a measure to Values and turn on Value Heatmap (Pro): same. With an active
"chipslicer-hierarchy-pro" plan, both render.
