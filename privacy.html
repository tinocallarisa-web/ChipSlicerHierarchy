Privacy Policy

Last updated: October 22, 2026 · Applies to Chip Slicer Hierarchy 1.3.0.0 and later

1. Data Collection

The Chip Slicer Hierarchy visual for Power BI does not collect, store, or transmit any personal information, user data, or business report data outside of your Power BI environment. It has no telemetry or analytics, and it sets no cookies and uses no browser storage.

2. Data Processing

All data processing is performed inside Power BI. The visual only uses the data provided by the Power BI platform to draw the chips of the hierarchy (up to three levels). The only thing it saves is its own formatting settings and the current selection, inside the report, as any Power BI visual does.

3. Network Requests and Third-Party Services

This visual makes no network requests and does not use any third-party services. Images in the Images well must be embedded in the data model as Base64 data URIs; web addresses are not loaded. The links on the start screen (shown when no data is bound) open only when you click them, through Power BI.

4. Licensing

Licence status is read exclusively through Microsoft's official Power BI licensing API. No external authentication or payment processing is performed by this visual, and TCViz runs no licence server and receives no data from your report.

5. Children's Privacy

This visual is designed for business intelligence use by adults. We do not knowingly collect personal information from children under 13.
